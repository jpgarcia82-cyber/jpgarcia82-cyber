#### What's in this GitHub

I use AI-assisted development (Claude Code) to go from product idea to a **working, deployed system** myself, instead of only writing a spec and handing it off. It's the same instinct that shows up in the CV — automate the process, ship it, measure it — applied to my own tooling.

**[`noticias`](https://github.com/jpgarcia82-cyber/noticias)** — a real-time sentiment analysis tool for YouTube comments, built serverless on Cloudflare Workers. Point it at a topic (a brand, a candidate, an election), and it pulls comments via the YouTube Data API, scores sentiment, and renders the results as live charts — no backend to manage, no local server. It's a small-scale version of the same problem I solve at work: turning raw customer/public signal into a decision-ready view, fast.

Why it's here: it's proof I can direct AI tools to build and ship a real, deployed product end-to-end — architecture, API integration, data visualization, deployment — the same muscle I bring to leading product and engineering teams, just exercised solo and hands-on.
